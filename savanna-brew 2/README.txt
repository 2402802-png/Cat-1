SAVANNA BREW CAFÉ WEBSITE
Introduction to Web Development — HTML & CSS Assignment

PROJECT CONTENTS
- index.html: Home page
- about.html: About Us page
- menu.html: Menu page with three KES price tables
- gallery.html: Gallery page with eight figures and captions
- contact.html: Contact details, opening hours and reservation enquiry form
- css/style.css: Shared external stylesheet
- images/: Local SVG illustration placeholders

HOW TO OPEN
1. Extract the project folder.
2. Open the savanna-brew folder in Visual Studio Code.
3. Open index.html in a browser, or use the Live Server extension if installed.
4. Use the navigation links to visit all five pages.

IMAGE NOTE
The assignment brief lists photo assets such as hero.jpg, latte.jpg and gallery-1.jpg.
This project includes local SVG illustration placeholders so that image paths work immediately.
Replace the SVG files in the images folder with suitable café photographs if required, and update
the corresponding image filenames in the HTML/CSS to match. The about-owner.svg image is an
illustration placeholder, not a real portrait of the fictional café owner.

IMPORTANT FORM NOTE
The assignment permits HTML and CSS only. The reservation form uses a mailto action, which
opens the visitor's default email application; it does not provide server-side booking storage
or automatic confirmation.

VALIDATION
Before submission, validate each HTML page at https://validator.w3.org/ and the stylesheet at
https://jigsaw.w3.org/css-validator/. Record any remaining warnings here after validation.
This README does not claim that external validation has already been performed.
